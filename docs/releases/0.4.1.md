**English**

- **Fixed** The Diagnostics section in Settings no longer shows the “Update remnants / Inspect and Clean” row. The report export remains, while the low-level update staging safety check stays in place.
- **Improved** Global safety mute remains an icon-only control at the top-right of the main panel. Its foreground turns black on hover, and the active state now matches the muted-speaker icon and red used by device rows.
- **Improved** The Mute All control now shares the same 26pt height and right-side spacing as the Settings control for consistent alignment.
- **Fixed** Closing Settings now clears a previously presented update-check failure while preserving download and installation errors. Failed background checks retry after 30 minutes instead of every minute.
- **Fixed** An older update check can no longer overwrite a download or skip action.
- **Fixed** Added missing English copy for app states, effect states, and common app-audio errors.
- **Improved** During high-frequency global-mute polling, input devices are read only while the Microphone page is visible; hidden panels and the Output page no longer scan the microphone HAL.
- **Improved** The Settings window now sizes to its current content instead of using a fixed height or leaving a blank row at the bottom.
- **Docs** Both product homepages now state where Mute All is located, and the UI preview cache was refreshed.
