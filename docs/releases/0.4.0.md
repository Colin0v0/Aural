**中文**

- **更名** 产品、应用模块、构建脚本、下载资产和 Bundle ID 统一迁移到 Auxmo；0.4.0 使用新身份 `com.colin0v0.auxmo.app`，不迁移旧品牌配置。
- **新增** 主面板“全部静音”：临时静音 Auxmo 能观察到的 App 音频，包括开启后才开始播放的 App；关闭后恢复各 App 原有的静音意图。
- **改进** 切换输出、只读电平会话以及正在播放的新 App 都使用同一套安全静音状态，不靠保存和恢复整套音频配置。
- **重构** 应用音频会话统一通过一个状态下发入口设置增益、有效静音与音效，减少多条路径漏掉静音状态的风险。
- **改进** 全局安全静音开启期间缩短应用播放状态轮询窗口，降低新播放 App 在下一轮接管前短暂出声的机会。
- **文档** 同步更新 Auxmo 首页、版本号、问题模板、诊断和验证边界。自动化测试仍不代表全部真机、蓝牙时序或漏音场景已经验收。

**English**

- **Renamed** The product, app modules, build scripts, release assets, and Bundle ID now use Auxmo. Version 0.4.0 uses the new identity `com.colin0v0.auxmo.app` and does not migrate legacy configuration.
- **Added** A **Mute All** control in the main panel. It temporarily silences app audio observed by Auxmo, including apps that start playing after safety mute is enabled. Turning it off restores each app's own mute intent.
- **Improved** Output switching, read-only meter sessions, and newly playing apps share one safety-mute state instead of saving and restoring a complete audio configuration.
- **Refactored** App audio sessions now apply gain, effective mute, and effects through one state path, reducing the chance that an update route misses mute state.
- **Improved** App playback observation runs at a shorter interval while global safety mute is active, reducing the window in which a newly playing app can be heard before the next takeover pass.
- **Docs** Updated the Auxmo homepages, version metadata, issue form, diagnostics, and validation limits. Automated tests still do not prove every physical device, Bluetooth transition, or leak scenario.
