**中文**

- **新增** 菜单栏设备图标开关，可跟随当前系统输出显示耳机、电脑、显示器或多设备组合图标。
- **改进** 设备图标与菜单栏电量目标相互独立，固定电量设备不会覆盖当前输出图标。

**English**

- **Added** A menu bar device icon that follows the current output for headphones, computers, displays, and multi-device routes.
- **Improved** The device icon is independent of the pinned battery target, so battery settings no longer override the current output icon.
