**中文**

- **新增** 本地诊断报告导出，记录音频状态与近期错误，不自动上传。
- **修复** 空间效果开启时，应用静音或音量归零后混响尾音仍继续输出的问题。
- **修复** 路由恢复后再次短暂等待被误判超时，以及音频格式变化后未重建重放端的问题。
- **改进** 路由等待超时后立即暂停重放，保留静音捕获；设置页底部版本号可点击打开 GitHub。

**English**

- **Added** Local diagnostic report export with audio state and recent errors. Reports are not uploaded automatically.
- **Fixed** Reverb tails could remain audible after muting an app or setting its volume to zero.
- **Fixed** A stale route timer could cause an immediate timeout during a later transition, and audio format changes did not rebuild playback.
- **Improved** Route timeouts now suspend playback immediately while keeping mute capture alive. The version label in Settings opens GitHub.
