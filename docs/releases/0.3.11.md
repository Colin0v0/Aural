**中文**

- **修复** 音效配置和自定义预设的损坏记录不再被当成空配置；读取失败时禁止覆盖原记录，并提供明确的重新读取入口。
- **修复** 音效读取失败不再阻止应用音量、静音和明确选择的路由；预设读取失败不再禁用手动 EQ、空间、动态和声道编辑。错误保留，坏记录不覆盖。
- **新增** 设置中的更新残留检查与清理入口。完整确认镜像未连接并经用户确认后，仅清理失效挂载标记，保留安装包和旧版本备份。
- **改进** 更新日志按 1 MiB 上限轮转，保留当前与上一份；App 与 helper 共用跨进程写入锁。
- **改进** 旧本地构建按明确路径归档，运行中的应用包不能被构建脚本移动或替换。
- **修复** 设置值无法解析时不再自动套用默认值；只有新电量来源键不存在时才迁移旧版布尔设置。
- **修复** 更新解包和镜像卸载失败会保留现场并报告路径，不再忽略清理错误或在未确认卸载时删除暂存目录。
- **重构** 分离配置状态、音效编辑、电平计时器和应用协调职责；本地 Debug、Release 与发布产物使用独立目录。
- **修复** 应用路由损坏、设备句柄复用、更新隔离属性和更新回滚失败的处理边界。

**English**

- **Fixed** Corrupt effect and custom-preset records are no longer treated as empty configuration. Writes are blocked until the record is readable, with an explicit reload action.
- **Fixed** Unreadable effects no longer block app gain, mute, or explicit routes. Unreadable presets no longer disable manual EQ, spatial, dynamics, or channel editing. Errors remain visible and corrupt records are retained.
- **Added** Update-remnant inspection and cleanup in Settings. After a complete image check and user confirmation, cleanup removes only a stale mount record, keeping installer files and recovery backups.
- **Improved** Update logs rotate at 1 MiB with one previous file. The app and helper share a cross-process write lock.
- **Improved** Legacy local builds are archived by explicit path, and build scripts cannot move or replace an active app bundle.
- **Fixed** Unreadable settings no longer silently use defaults. The legacy battery migration runs only when the new battery-source key is absent.
- **Fixed** Update extraction and image-detach failures retain evidence and report paths instead of swallowing cleanup errors or deleting staging data before unmount is confirmed.
- **Refactored** Configuration state, effect editing, meter timing, and app coordination now have separate owners. Local Debug, Release, and release assets use separate directories.
- **Fixed** Failure boundaries for corrupt app routes, recycled device handles, quarantine attributes, and update rollback failures.
