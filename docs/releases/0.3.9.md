**中文**

- **修复** 自定义输出全部离线或被移出组后，不再改用组内其他输出；暂停该应用的 Aural 重放，保留持续静音捕获。播放器进度不会因此暂停。
- **改进** 部分目标在线时只使用已选的在线设备，保留完整选择；目标确认恢复后沿用原音量、静音及音效。正常等待显示灰色暂停标记。
- **文档** 重做中英文首页，补充界面示例、诊断反馈入口和验证边界。此改动不代表系统级隐私隔离，真机断连与切换仍需验收。

**English**

- **Fixed** When all custom outputs disconnect or are removed from the group, Aural pauses that app's replay and retains continuous mute capture instead of using other group outputs. This does not pause the player's timeline.
- **Improved** Partially available routes use only selected online devices and retain the complete selection. Confirmed targets resume with the existing gain, mute, and effects settings. Normal waiting shows a gray pause indicator.
- **Docs** Rebuilt both product homepages with UI previews, a diagnostic report form, and validation limits. This change is not system-wide privacy isolation; real-device disconnects and transitions still need acceptance testing.
